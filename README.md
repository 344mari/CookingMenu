# CookingMenu
晩御飯考えるやつ

冷蔵庫の在庫から献立を提案する、スマホ向けの Web アプリです。
`index.html` 1ファイルで動き、外部への通信はしません（在庫データはブラウザの localStorage に保存）。

## ファイル
| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体（HTML / CSS / JavaScript） |
| `recipes.json` | レシピデータ。自由に追加・編集してください |

## 使い方
画面下のボタンで「在庫管理」と「献立」の2画面を切り替えます。在庫があるときは「献立」、ないときは「在庫管理」から開きます。

### 在庫管理
1. 「食材を登録」で食材名を検索するか、カテゴリのプルダウンで選んで食材を表示し、タップして選び（複数可）、食材ごとに賞味期限を入れて「○件を在庫に追加」
   - 最初は食材を表示しません。検索欄に入力するか、カテゴリを選んだときだけ候補が出ます（プルダウンを「カテゴリ」に戻すと閉じます）
   - 検索はひらがな・カタカナどちらでも可（例: `たまねぎ`、`べーこん`）。検索とカテゴリをまたいで選んだ食材はまとめて追加されます
   - 選んだ食材は一覧になり、それぞれに購入日・賞味期限・残りの量を入れられます（どれも任意。購入日は今日が入った状態で始まります）。× で選択から外せます
   - 野菜など賞味期限がはっきりしないものは、購入日だけ入れておくと在庫一覧に「購入から○日」と表示されます
   - 残りの量は、数えられるもの（卵、冷凍餃子など）は「数で入力」で −／＋ と単位（個・本・袋・パックなど）、数えにくいもの（牛乳、野菜の使いかけなど）は「たっぷり／半分くらい／少し」から選びます
2. リストにない既製品（冷凍餃子、レトルトカレーなど）は、検索欄に名前を入れて「＋「○○」を既製品として追加」を押します
   - 既製品は在庫として管理できますが、献立の材料には使いません
   - 入力した名前がリストの食材名（またはよみ）と完全に一致するときは、既製品ではなくその食材として扱います
3. 在庫一覧では、賞味期限が3日以内（期限切れ含む）のものが赤く上に並びます
   - 名前か期限の表示を押すと、購入日・賞味期限・残りの量を変更できます。賞味期限を空にして保存すると「期限なし」になります
   - 賞味期限がないものは、購入日の古い順に並びます
   - 数で管理しているものが残り0になると、在庫から削除するか確認します（削除しなかった場合、残り0のものは献立の材料に使いません）
   - 期限が近いものの件数は、画面下の「在庫管理」にも赤い数字で出ます

### 献立
1. 調理時間と気分を選んで「献立を提案」
   - 在庫で揃う割合が高く、期限が近い食材を使うレシピほど上位に、最大3件表示します（既製品は数えません）
   - 在庫を変えてから献立画面に戻ると、表示中の提案は最新の在庫で出し直されます

## recipes.json の編集方法
1件ごとに次の形で書きます。

```json
{
  "name": "肉じゃが",
  "ingredients": ["じゃがいも", "玉ねぎ", "にんじん", "豚肉"],
  "time": 30,
  "type": "和食",
  "url": "https://example.com/recipe"
}
```

| 項目 | 説明 |
| --- | --- |
| `name` | 料理名 |
| `ingredients` | 主な食材（調味料は入れない）。**アプリの食材リストと同じ表記**で書く（下記） |
| `time` | 調理時間（分、数字） |
| `type` | `和食` / `洋食` / `中華` / `エスニック` のどれか |
| `url` | 公式サイトのレシピページ URL。空文字 `""` にするとリンクを表示しません |

注意:
- 全体は `[ ... ]` で囲み、各レシピの間はカンマ `,` で区切ります。最後のレシピの後ろにはカンマを付けません。
- 食材の照合は完全一致です。`豚こま肉` ではなく `豚肉` のように、リストの表記に合わせてください。

使える食材名（`index.html` の `CATALOG` に定義。ここに追加すれば登録画面にも出ます。漢字を含む名前は `READINGS` によみを足すと、ひらがなでも検索できます）:

- 野菜・きのこ: 玉ねぎ, にんじん, じゃがいも, キャベツ, 白菜, 大根, ねぎ, ピーマン, なす, トマト, きゅうり, ほうれん草, ブロッコリー, もやし, レタス, かぼちゃ, しめじ, えのき, ごぼう, にら
- 肉: 豚肉, 鶏もも肉, 鶏むね肉, 牛肉, ひき肉, ベーコン, ハム, ウインナー
- 魚介: 鮭, さば, ぶり, えび, いか, ツナ缶
- 卵・乳製品・大豆: 卵, 牛乳, チーズ, バター, 豆腐, 油揚げ, 納豆
- フルーツ: りんご, バナナ, みかん, オレンジ, グレープフルーツ, レモン, いちご, ぶどう, キウイ, もも, なし, 柿, パイナップル, メロン, すいか, ブルーベリー, アボカド
- 主食・その他: ごはん, うどん, パスタ, 中華麺, カレールウ, キムチ, こんにゃく

## GitHub Pages で公開する
1. この2ファイルを `main` ブランチに push
2. GitHub のリポジトリで Settings → Pages → Build and deployment
3. Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/CookingMenu/` で開けます

※ `index.html` をファイルとして直接開くと `recipes.json` を読み込めません（ブラウザの制限）。
手元で試すときは `python -m http.server` などでローカルサーバーを立てて開いてください。
