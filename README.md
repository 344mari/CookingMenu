# CookingMenu
晩御飯考えるやつ

冷蔵庫の在庫から献立を提案する、スマホ向けの Web アプリです。
`index.html` 1ファイルで動き、外部への通信はしません（在庫データはブラウザの localStorage に保存）。

## ファイル
| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体（HTML / CSS / JavaScript） |
| `recipes.json` | レシピデータ。自由に追加・編集してください |

## 使い方
画面下のボタンで「在庫管理」と「献立」の2画面を切り替えます。在庫があるときは「献立」、ないときは「在庫管理」から開きます。

### 在庫管理
1. 「食材を登録」で食材名を検索するか、カテゴリのプルダウンで選んで食材を表示し、タップして選び（複数可）、食材ごとに賞味期限を入れて「○件を在庫に追加」
   - 最初は食材を表示しません。検索欄に入力するか、カテゴリを選んだときだけ候補が出ます（プルダウンを「カテゴリ」に戻すと閉じます）
   - 検索はひらがな・カタカナどちらでも可（例: `たまねぎ`、`べーこん`）。検索とカテゴリをまたいで選んだ食材はまとめて追加されます
   - 選んだ食材は一覧になり、それぞれに購入日・賞味期限・残りの量を入れられます（どれも任意。購入日は今日が入った状態で始まります）。× で選択から外せます
   - 野菜など賞味期限がはっきりしないものは、購入日だけ入れておくと在庫一覧に「購入から○日」と表示されます
   - 購入日がわからないものは、購入日の右上の「不明にする」を押すと空になり、欄に「不明」と出ます（賞味期限も「なしにする」で空にできます）。もう一度欄をタップすれば日付を選び直せます
   - 残りの量は、数えられるもの（卵、冷凍餃子など）は「数で入力」で −／＋ と単位（個・本・袋・パックなど）、数えにくいもの（牛乳、野菜の使いかけなど）は「たっぷり／半分くらい／少し」から選びます
2. リストにない既製品（冷凍餃子、レトルトカレーなど）は、検索欄に名前を入れて「＋「○○」を既製品として追加」を押します
   - 既製品は在庫として管理できますが、献立の材料には使いません
   - 入力した名前がリストの食材名（またはよみ）と完全に一致するときは、既製品ではなくその食材として扱います
3. 在庫一覧では、賞味期限が3日以内（期限切れ含む）のものが赤く上に並びます
   - 名前か期限の表示を押すと、購入日・賞味期限・残りの量を変更できます。編集欄でも「不明にする」「なしにする」で購入日・賞味期限を空にできます
   - 賞味期限がないものは、購入日の古い順に並びます
   - 数で管理しているものが残り0になると、在庫から削除するか確認します（削除しなかった場合、残り0のものは献立の材料に使いません）
   - 期限が近いものの件数は、画面下の「在庫管理」にも赤い数字で出ます

### 共有（CSV）
在庫・マイ献立・カレンダーの記録は、それぞれ CSV ファイルで書き出して共有できます。同居人などとそろえたいときに便利です。
- 在庫：在庫管理画面のいちばん下「🔁 在庫を共有」（ファイル名 `zaiko_日付.csv`）
- マイ献立：献立画面の「📝 マイ献立」の下「🔁 マイ献立を共有」（`kondate_日付.csv`、列は `料理名, タイプ, 調理時間, 材料, 調味料, URL`。材料と調味料は「、」区切りで、使う量は `卵 2個`・`醤油 大さじ2`・`玉ねぎ 半分くらい` のように名前の後ろにスペースを空けて書きます）
- カレンダー：カレンダー画面のいちばん下「🔁 カレンダーを共有」（`calendar_日付.csv`、列は `日付, 献立` で1行に1品）

どれも使い方は同じです。

1. 「CSVで書き出す」を押すと、CSVファイルを書き出します
   - スマホでは共有メニューが開くので、LINE やメールでそのまま送れます（共有メニューが使えない端末ではファイルとして保存されます）
2. 受け取った人は「CSVを読み込む」でそのファイルを選び、反映のしかたを選びます
   - **置き換える**: 今の在庫を消して、CSVの内容にします（相手と同じ在庫にしたいとき）
   - **追加する**: 今の在庫はそのままで、CSVの内容を足します（マイ献立は同じ料理名を上書き、カレンダーは同じ日の同じ献立を重ねて登録しません）

在庫のCSVの列は `名前, 種類, 購入日, 賞味期限, 残り数, 単位, 残り目安` です。Excel などで作ったり直したりもできます。
- 必須なのは `名前` の列だけです。列の順番は自由で、ない列は空として扱います
- `種類` は `食材` か `既製品`。空なら、食材リストにない名前を既製品とみなします
- 日付は `2026-10-14` か `2026/10/14` の形で書きます
- 残りの量は、数なら `残り数` と `単位`（個・本・袋・パック・枚・切れ・玉・g）、目安なら `残り目安`（たっぷり・半分くらい・少し）に書きます
- 文字コードは UTF-8 と Shift_JIS（Excel で保存したもの）のどちらでも読めます

### 献立
1. 調理時間と気分を選んで「献立を提案」
   - 在庫で揃う割合が高く、期限が近い食材を使うレシピほど上位に、最大3件表示します（既製品は数えません）
   - 在庫を変えてから献立画面に戻ると、表示中の提案は最新の在庫で出し直されます

### マイ献立
献立画面の「📝 マイ献立」→「＋ 献立を追加」から、自分の献立を登録できます。
- 料理名・調理時間・タイプ・使う材料・調味料・レシピのURL（任意）を入れて「保存」
- 材料は食材リストから検索やカテゴリで選びます（リストにない材料も追加できますが、在庫とは照らし合わせられません）
- 調味料はよく使うものをタップで選び、ないものは「ほかの調味料」に入力して追加します。調味料は提案カードに表示するだけで、在庫とは照らし合わせません
- 「⚖️ 使う量」で、選んだ材料・調味料ごとに使う量を入れられます（任意）
  - 「数で入力」: 数と単位（個・本・袋・パック・枚・切れ・玉・g・ml・大さじ・小さじ・カップ）
  - 「少し／半分くらい／全部」: 数えにくいもの
  - 作ったときの在庫を減らす画面に、この量が最初から入ります（下の「カレンダー」を参照）
- 登録した献立は「マイ献立」の印付きで献立の提案に出てきます。一覧の「編集」「×」で直したり消したりできます

### カレンダー
画面下の「📅 カレンダー」で、作った献立を日ごとに記録できます（月曜始まり）。
- 日付を押して、「作った献立を選ぶ」から選ぶか料理名を入力し、「この日に登録」を押します（1日に何件でも登録できます）
- 献立の提案カードの「📅 今日作った」を押すと、今日の日付に登録されます
- 献立リストから選んで登録すると、使った材料の在庫を減らす画面が出ます（在庫にある材料だけ表示）
  - 数で管理しているもの（卵など）は使った数を入れます。同じ食材が複数あるときは期限の近いものから減らし、0になったら在庫から消えます
  - マイ献立で使う量を入れておくと、その量が最初から入ります（例: 卵 2個 → 使った数 2、玉ねぎ 半分くらい → 残り「半分くらいになった」）。在庫と単位が違うとき（醤油 大さじ2 と在庫 1本 など）は 0 になるので、必要なら直してください
  - それ以外は「そのまま／半分くらいになった／少しになった／使い切った（在庫から消す）」から選びます
  - 「在庫を減らして記録」で反映、「記録だけ」なら在庫は変えずにカレンダーにだけ登録します
  - 料理名を自由入力したときは、在庫を減らす画面は出ずにそのまま登録します
- 登録した献立は、その日の一覧の × で消せます。‹ › で月を移動、「今日に戻る」で今月に戻ります

※ マイ献立とカレンダーの記録はこの端末のブラウザに保存されます。共有したいときは下の CSV を使います

## recipes.json の編集方法
1件ごとに次の形で書きます。

```json
{
  "name": "肉じゃが",
  "ingredients": ["じゃがいも", "玉ねぎ", "にんじん", "豚肉"],
  "time": 30,
  "type": "和食",
  "url": "https://example.com/recipe"
}
```

| 項目 | 説明 |
| --- | --- |
| `name` | 料理名 |
| `ingredients` | 主な食材（調味料は入れない）。**アプリの食材リストと同じ表記**で書く（下記） |
| `time` | 調理時間（分、数字） |
| `type` | `和食` / `洋食` / `中華` / `エスニック` のどれか |
| `url` | 公式サイトのレシピページ URL。空文字 `""` にするとリンクを表示しません |

注意:
- 全体は `[ ... ]` で囲み、各レシピの間はカンマ `,` で区切ります。最後のレシピの後ろにはカンマを付けません。
- 食材の照合は完全一致です。`豚こま肉` ではなく `豚肉` のように、リストの表記に合わせてください。

使える食材名（`index.html` の `CATALOG` に定義。ここに追加すれば登録画面にも出ます。漢字を含む名前は `READINGS` によみを足すと、ひらがなでも検索できます）:

- 野菜・きのこ: 玉ねぎ, にんじん, じゃがいも, キャベツ, 白菜, 大根, ねぎ, ピーマン, なす, トマト, きゅうり, ほうれん草, ブロッコリー, もやし, レタス, かぼちゃ, しめじ, えのき, ごぼう, にら
- 肉: 豚肉, 鶏もも肉, 鶏むね肉, 牛肉, ひき肉, ベーコン, ハム, ウインナー
- 魚介: 鮭, さば, ぶり, えび, いか, ツナ缶
- 卵・乳製品・大豆: 卵, 牛乳, チーズ, バター, 豆腐, 油揚げ, 納豆
- フルーツ: りんご, バナナ, みかん, オレンジ, グレープフルーツ, レモン, いちご, ぶどう, キウイ, もも, なし, 柿, パイナップル, メロン, すいか, ブルーベリー, アボカド
- 主食・その他: ごはん, うどん, パスタ, 中華麺, カレールウ, キムチ, こんにゃく
- 調味料: 醤油, みりん, 酒, 砂糖, 塩, こしょう, 味噌, 酢, ごま油, サラダ油, オリーブオイル, マヨネーズ, ケチャップ, ソース, ポン酢, めんつゆ, だし, コンソメ, 鶏がらスープの素, オイスターソース, 豆板醤, カレー粉, にんにく, しょうが（マイ献立の調味料の候補と共通。在庫に登録しておくと、マイ献立を作ったときに減らせます）

## GitHub Pages で公開する
1. この2ファイルを `main` ブランチに push
2. GitHub のリポジトリで Settings → Pages → Build and deployment
3. Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/CookingMenu/` で開けます

※ `index.html` をファイルとして直接開くと `recipes.json` を読み込めません（ブラウザの制限）。
手元で試すときは `python -m http.server` などでローカルサーバーを立てて開いてください。
